# KDE Connect "Send To" for Windows 11

Add a **right-click → Send to → "Send to Your Phone"** entry to Windows Explorer that shares files to your phone via KDE Connect — no flashing console window, with a progress popup while it transfers.

## What's included

| File | Purpose |
|------|---------|
| `send-kdeconnect.ps1` | The sharing script: shows a progress popup, runs `kdeconnect-cli.exe --share` on your device, reports errors |
| `kdeconnect.ico` | KDE Connect app icon extracted from `kdeconnect-app.exe` — used for the shortcut icon |
| `setup-kdeconnect-sendto.ps1` | Extracts the icon and creates/refreshes the Send To shortcut |
| `Send to Your Phone.lnk` | *generated by setup* — the actual shortcut in your `shell:sendto` folder (not committed) |

## Prerequisites

- KDE Connect installed on Windows (Microsoft Store build works — `kdeconnect-cli.exe` ends up in `%LOCALAPPDATA%\Microsoft\WindowsApps\`)
- Phone paired and connected in the KDE Connect app
- PowerShell available (Windows 11 has it by default)

## One-time setup

1. Open **Windows Run** (`Win + R`), paste `shell:sendto`, press Enter. That folder opens.
2. Run `setup-kdeconnect-sendto.ps1` (right-click → Run with PowerShell, or `powershell -ExecutionPolicy Bypass -File setup-kdeconnect-sendto.ps1`).
   - It extracts the KDE Connect icon and creates the shortcut `Send to Your Phone.lnk` in the Send To folder.
   3. Done. Right-click any file → **Send to** → **Send to Your Phone**.

## Changing the variables

No variables to change — the script auto-detects your phone's KDE Connect name using `kdeconnect-cli.exe --list-available --name-only`. Just make sure your phone is paired and connected before sending.

To rename the shortcut / menu entry, edit `setup-kdeconnect-sendto.ps1` and change `'Send to Your Phone.lnk'` (both the `$lnkPath` line and the cleanup line), then re-run setup.

If you send several files at once, Windows may launch one transfer per file — each gets its own progress popup.
